# Cocineros Rubyistas: una suite de tests 5× más rápida

Lightning talk (5 min) para la meetup de Ruby Sur, Buenos Aires, 20 de octubre de 2026.

La versión escrita, con todos los números y el detalle técnico, está en [ARTICULO.md](ARTICULO.md).

## Presentar

Publicada en https://fesilvajacquier.github.io/test-perf-talk/.


Abrí `index.html` en el navegador. Todo está en el repo (reveal.js 5.2.1 y fuentes en `vendor/` y `fonts/`), así que funciona sin conexión.

- `S`: vista del orador, con notas y tiempos estimados por slide.
- `T`: muestra u oculta el timer de cocina (cuenta 5 minutos desde la segunda slide; se pone rojo en el último minuto).
- `R`: reinicia el timer.
- `F`: pantalla completa.

Si el navegador bloquea la vista del orador con `file://`, serví la carpeta: `python3 -m http.server 8000`.

## Memes

`python3 build_memes.py` regenera `img/memes/` a partir de `img/templates/` (necesita Pillow y las fuentes Impact y DejaVu).
